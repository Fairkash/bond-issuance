# Bond Issuance Contract

A smart contract for creating and managing fixed-term on-chain bonds with
defined yield rates and maturity conditions.

## Key Functions
- `issue-bond` — Create a new bond offering
- `purchase-bond` — Acquire bond units during issuance period
- `redeem-bond` — Claim principal plus yield after maturity
- `get-bond` — Retrieve bond parameters and status
- `set-issuer` — Assign authorized bond issuers

Designed for fundraising, treasury management, and protocol-backed financing.
